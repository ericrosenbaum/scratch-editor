# Starter project assets

The `.sb3` files here are real, self-contained Scratch projects (blocks +
bundled costumes/sounds) and the `.png` files are their stage thumbnails. They
are shown in the "Get Started" welcome modal for the Speech to Text / Q&A
extensions.

## Regenerating

The projects are generated from a single source of truth — a block-builder DSL
in [`../../../../scripts/generate-starter-projects.js`](../../../../scripts/generate-starter-projects.js).
To change a project's scripts, characters, or backdrops, edit the project
definitions there and re-run:

```
node packages/scratch-gui/scripts/generate-starter-projects.js
```

It fetches the referenced library assets from the Scratch CDN (cached under
`/tmp/scratch-asset-cache`) and writes each `<id>.sb3` here. Custom Q&A datasets
(Dinosaur Facts, Space Facts, Ocean Facts) are written into the project's
`extensionData` and restored on load by the Q&A extension's serialization.

The thumbnails are regenerated by loading each project in the editor and
screenshotting the stage (see the project's test tooling).
